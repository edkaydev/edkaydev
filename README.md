## About Me

I'm a Computer Science student at **Uganda Martyrs University** and a software engineer based in Uganda. I enjoy turning ideas into useful software, solving technical problems, and learning through hands-on engineering.

My work spans full-stack web development, application deployment, IT systems support, and cloud infrastructure. I also explore AI-assisted development to improve my workflow while strengthening my understanding of the code I build.

Beyond engineering, I lead the **UMU Tech Community**, helping students learn, collaborate, and build through technology.

- 🔭 Building practical web applications and digital products
- ☁️ Exploring Linux, cloud infrastructure, Docker, and DevOps
- 🤖 Using AI tools to support development and debugging
- 🤝 Growing technology communities and sharing knowledge
- 🎓 BSc Computer Science, Uganda Martyrs University
